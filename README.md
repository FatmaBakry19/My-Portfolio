# Fatma Bakry — Portfolio Website

A responsive, animated, single-page portfolio website built with HTML, CSS, and vanilla JavaScript. No build tools or dependencies are required.

## Publish it

### GitHub Pages
1. Create a new GitHub repository (for example, `fatma-portfolio`).
2. Upload `index.html` to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
5. Wait for GitHub Pages to publish the site and open the URL shown there.

### Netlify
1. Open Netlify and choose **Add new site → Deploy manually**.
2. Drag the folder containing `index.html` into the deploy area, or connect the GitHub repository.

## Before publishing publicly
- Review all text and ensure it accurately represents your current skills and experience.
- Add verified links or images for certificates only when you have them. The site intentionally does not invent dates, IDs, or credential verification links.
- Review project cards and replace proposed/learning examples with finished work and working repository/demo links when available.
- Add a contact email if you want visitors to contact you directly.

## Current limitations
- This is a complete publishable **static frontend**. It does not include a backend, database, admin dashboard, or server-side form handling.
- The contact form opens the visitor's default email application with a prepared message; it does not send or store messages itself.
- No third-party libraries or build step are required.
